Política de Privacidade — Meu Caixa

Última atualização: 11 de novembro de 2026

O que é o Meu Caixa

O Meu Caixa é um aplicativo pessoal de controle financeiro, desenvolvido e usado por Vinicius Lima. Ele mostra e registra lançamentos em uma planilha do Google Sheets que pertence ao próprio usuário.

Quais dados o app acessa

Ao entrar com a conta Google, o app pede permissão para ver e editar planilhas do Google Sheets (escopo https://www.googleapis.com/auth/spreadsheets). Esse acesso é usado somente para ler e gravar os lançamentos financeiros na planilha indicada nas configurações do app. O app não lê e-mails, contatos, arquivos do Drive nem qualquer outro dado da conta.

Como os dados são usados e guardados

Os dados da planilha são exibidos no próprio aparelho do usuário. O token de acesso fica armazenado apenas nesse aparelho. Não existe servidor do Meu Caixa: o aplicativo conversa diretamente com a API do Google Sheets.

Compartilhamento

Os dados não são vendidos, compartilhados, transferidos nem divulgados a terceiros, e não são usados para publicidade ou para treinar modelos de inteligência artificial.

O uso e a transferência, para qualquer outro app, das informações recebidas das APIs do Google seguirão a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Como revogar o acesso

O acesso pode ser retirado a qualquer momento em myaccount.google.com/permissions. Ao sair do app (botão de configurações), o token é removido do aparelho.
